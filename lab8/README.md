# 🎭 Meme Generator

Простое графическое приложение для создания мемов из изображений с добавлением текста сверху и снизу.

## 📝 Описание

Meme Generator — это десктопное приложение с графическим интерфейсом на `wxPython`, которое позволяет:

- Загружать изображения в форматах PNG, JPG, JPEG
- Добавлять текст сверху и снизу изображения (автоматически переводится в верхний регистр)
- Настраивать размер шрифта (от 20 до 200 пикселей)
- Предварительно просматривать результат перед сохранением
- Сохранять готовый мем в формате PNG

Текст автоматически центрируется по горизонтали и имеет чёрную обводку для лучшей читаемости на любом фоне.

## 🚀 Инструкции по запуску

### Требования

- Python 3.8 или выше
- Установленные зависимости из `requirements.txt`

### Установка

1. Клонируйте репозиторий или скачайте файлы приложения

2. Установите необходимые библиотеки:

```bash
pip install -r requirements.txt
```
```bash
Содержимое requirements.txt:
Pillow>=10.0.0
wxPython>=4.2.0
````
## Запуск
python3 main.py


## 📖 Краткая справка
Основное окно
Приложение имеет следующие элементы управления:
```bash
Элемент	Назначение
Текст сверху	              Поле для ввода верхней надписи на меме
Текст снизу	                Поле для ввода нижней надписи на меме
Размер шрифта	              Регулировка размера шрифта (20–200 пикселей)
Загрузить изображение	      Выбор файла-исходника для мема
Создать мем	                Генерация мема с введённым текстом
Сохранить мем	              Сохранение сгенерированного мема в PNG-файл
```
